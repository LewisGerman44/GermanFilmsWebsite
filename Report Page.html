Website Report

Colours and Contrast

When creating this website I wanted to make sure that I included some accessiblity and responisve features within my website. The first thing I included in my website, was making sure the colour scheme I had chosen would fit within the contrast code. The colours I went for were dark blue and white, in the navigation bar I made the background dark blue and the text white, whereas within the body of the website I went with the white background and dark blue text. When I ran these colours through a contrast checker it cam back with a score of 14.38:1 and that these colours passed the WCAG (Web Content Accessiblity Guidelines) triple A mark.

Media Query

The second thing I included within my webiste was the compatibility to be used on a mobile device as well, I did this by including media queries within my css file. To create this media query I made the main navigation bar become a block when opened on a mobile device. As well as this, I also shrunk down the size of the text and image when the website is opened on a mobile device. Furthermore, I also made the text wrap when the screen size become smaller. I would of like to include another query if I had more time to also be compatible with use on either a tablet or an ipad.

Introduction to accessiblity

Information I have used: W3C Introduction to accessiblity

When I was creating my website I found it very important to research the meaning of accessiblity within a website. The meaning of web accessiblity is using tools and technologies that can be used to help people with disabilites and help them understand and navigate the web without any hassle. However, web accessiblity can also be helpful towards people with disabilites as well, such as old people, people using smaller screen devices, and people who slow internet connection/bandwith. Web accessiblity can help with many different types of disabilites, from physical and neurological disabilites, to visual, auditory, and speech.

POUR

Within a website accessiblity is the slogan known as pour (Perceivable, Operable, Understandable, Robust):

Perceivable:

Information I have used: Perceivable Guidlines

The first one is perceivable, this is making sure that the user is able to recognise the service and to be able to use it with all the senses that the user has avaiable. Some of the features to include are, providing transcripts for audio and videos, provide alt texts for images, and make sure to use text colours that appear cleary on the background colour.

Operable:

Information I have used: Operable guidlines

The second one is operable, this making sure the user is able to access the content and use it with whatever technology they have, (for example, voice commands). Some features to include are, allowing people to move/play/pause content, making sure interactive elements are big enough for the user and spaced out.

Understandable:

Information I have used: Understandable Guidlines

The third one is understandable, this making sure that the user understand the content withint the website and how it all works. Some features to include are, making sure that the website has a consistent look and behaves in the way that should, and also making sure it is clear the language of the webpage and if any changes are made that they have been indicated.

Robust:

Information I have used: Robust Guidlines

The final one is robust, this making sure that the content of the website is able to be interpreted reliably by a wide range of users. For example, making sure that the website code can be used by assitive technologies and is able to know what every interactive component can do and the state that they are in.
